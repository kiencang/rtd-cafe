{rtd-cafe} WP Cloudflare Optimizer

Dành cho WordPress dạng Blog & Tin tức

Triển khai nhanh cấu hình Cache & Bảo mật của Cloudflare cho WP cài trên VPS

🔒 Cam kết an toàn: Tool này chạy trực tiếp qua API Cloudflare. Chúng tôi không lưu trữ Token hay thông tin của bạn. Mã nguồn chạy trên Cloudflare Workers. API token khi tạo nên điều chỉnh các quyền vừa đủ dùng là Zone.Cache Rules (Edit), Zone.Transform Rules (Edit), Zone.WAF (Edit) và chỉ cần cho tên miền cụ thể cần nhắm tới. Sau khi chạy lệnh trên website này thì để an tâm nhất nên xóa API Token đó hoặc đổi nó sang Token khác.
⚠️ Tool này dành cho người đã hiểu Cloudflare cơ bản: Nếu bạn chưa biết Cache Rules & WAF là gì, hãy đọc các bài vừa được dẫn link. Ngoài ra bạn hoàn toàn có thể cấu hình thủ công, công cụ này chỉ giúp quá trình đó nhanh & ít sai sót hơn. Tool này không phù hợp cho WooCommerce, Membership, LMS. Nó chỉ phù hợp cho WordPress dạng blog, tin tức.
🔄 Cập nhật rule định kỳ: Nhìn chung các rule có tính ổn định cao, tuy nhiên để dự phòng thì sau khoảng 6 - 12 tháng bạn nên vào lại trang này để chạy lại lệnh, điều đó giúp các rule có tính cập nhật nhất.
💡 Sản phẩm thay thế: Nếu bạn không muốn dùng ứng dụng này, hãy tham khảo plugin rất tốt có tên Super Page Cache, nó có nhiều nét tương đồng với rtd-cafe.
Một số sai lầm phổ biến khi lấy Zone ID & cách khắc phục.
Yêu cầu quyền: Zone.Cache Rules (Edit), Zone.Transform Rules (Edit), Zone.WAF (Edit). Một số sai lầm phổ biến khi tạo API Token & cách khắc phục. Nên xóa hoặc đổi API Token sau khi dùng ứng dụng này.
Đảm bảo tên miền của bạn đang bật đám mây vàng (proxied) trên DNS Cloudflare thì các rule này mới có tác dụng.
Để whitelist tránh tự chặn chính mình. Sau này bạn đổi sang VPS khác thì IP sẽ thay đổi, bạn cần nhớ cập nhật thông tin này.
[Lưu ý nhỏ: Chức năng của hộp trên chỉ là để đảm bảo bạn là người dùng thực (một dạng CAPTCHA thân thiện), không phải xác nhận là bạn đã cài xong!]
⚠️ Lưu ý quan trọng: Tool sẽ GHI ĐÈ (Xóa & Thay thế) toàn bộ Cache Rules, WAF Rules và Transform Rules hiện có trên Zone này. Hãy sao lưu lại các rule nếu bạn đang có cấu hình riêng.
